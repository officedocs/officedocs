# OfficeDocs ドキュメント

OfficeDocs は、プライベートクラウドでドキュメント、文書作成、スプレッドシート、プレゼンテーション、フォーム、テーブルを提供し、すべての製品にプライベート設定可能な AI Agent を内蔵したセルフホスト型文書コラボレーションスイートです。
