# OfficeDocs-Dokumentation

OfficeDocs ist eine selbst gehostete Suite für Dokumentenzusammenarbeit mit Dokumenten, Textverarbeitung, Tabellen, Präsentationen, Formularen und strukturierten Tabellen in Ihrer Private Cloud sowie privat konfigurierbaren AI Agents in jedem Produkt.
