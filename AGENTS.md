# OfficeDocs product distribution

This repository owns OfficeDocs release metadata, product-facing README files and installation guidance. The application binaries are distributed as release assets; do not add large archives to Git.

Preserve the approved package filenames, signatures and checksums. Do not infer an open-source licence or rewrite technical identifiers for branding. Website source and all private operations data, credentials, analytics, lead records, handoffs and agent state belong outside this repository.

The original shimodocs/shimodocs repository is read-only. This repository is not the website repository. Check current visibility before publishing download links for anonymous visitors.

Verify documentation links, published asset names, full SHA256 values and archive integrity before releasing. Distinguish archive verification from runtime installation testing. Use decision-oriented commit messages with relevant Constraint, Confidence, Scope-risk, Tested and Not-tested trailers.
